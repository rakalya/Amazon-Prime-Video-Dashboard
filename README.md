# Amazon Prime Video Dashboard | Power BI

## Project Overview
This project presents an interactive dashboard built using Microsoft Power BI to analyze Amazon Prime Video content.

## Objectives
- Analyze the total number of titles available.
- Explore movies and TV shows.
- Analyze content by release year and genre.
- Understand content distribution by country.
- Explore ratings and content types.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization


## Key Learnings
- Data cleaning and transformation.
- Creating charts, cards, and slicers.
- Building interactive report navigation.
- Developing a data visualization dashboard.
